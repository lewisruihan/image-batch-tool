## 图片批量处理与直出工具

这是一款免安装的纯前端网页小工具，帮你把各种格式、尺寸的图片，一键变成整齐的 240x240 像素 PNG 图片，还能调用 AI 自动重命名。

### ✨ 核心功能

自动规整： 拖入图片自动居中缩放、四周留白，并强制转为 240x240 像素的 PNG 格式（保证体积 < 500KB）。

🤖 AI 智能重命名： 自动看图识物，把类似 IMG_123.jpg 的乱码名字，一键变成 黑猫_240x240.png。

🔒 本地处理，隐私安全： 图片缩放和转换全部在你的浏览器本地完成，原图绝不上传。（仅在使用 AI 命名时，会发送极小的缩略图给 AI 模型）。

### 🚀 快速上手 (三步搞定)

导入： 把图片（支持单张或批量）直接拖进网页里的虚线框。

重命名（可选）： 点击紫色的 “✨ AI 智能重命名” 按钮，等几秒钟，让 AI 帮你改好文件名。

下载： 勾选想要的图片，点击绿色的 “下载选中的图片”，直接保存到电脑。

### 🛠️ 部署与使用 (GitHub Pages)

本工具为纯前端单文件（index.html），无需任何后端环境，非常适合在 GitHub 托管：

将 index.html 上传到你的 GitHub 仓库。

开启该仓库的 GitHub Pages 功能（进入 Settings -> Pages -> Branch 选择 main 并保存）。

等待一两分钟，访问生成的 GitHub Pages 专属链接即可随时随地在线使用！

### ❓ 常见问题 (FAQ)

#### 传了 GIF 动图怎么不会动了？
工具设定为输出标准静态图。如果是动图，会自动提取第一帧转成高质量静态 PNG。

#### 为什么有的图片 AI 没改名成功？
可能是网络波动。如果 AI 没反应，系统会自动保留原来的名字，不影响你正常下载。

#### 一次能传多少张？
由于处理过程完全在本地进行，建议一次处理 100 张以内，放太多可能会让你的浏览器卡顿。

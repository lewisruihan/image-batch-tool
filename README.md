# 🖼️ 图片批量处理与智能切割工具

这是一款**免安装的纯前端网页工具**，专为快速生成 `240x240` 像素的标准 PNG 图片设计。最新版本集成了 AI 视觉切割、AI 智能重命名以及实时位置微调功能。

网址在这里哦：https://lewisruihan.github.io/image-batch-tool/

## ✨ 核心功能

* **📐 自动规整与实时微调：** 自动等比缩放、四周留白并限制体积。支持通过滑块**实时调整**留白比例及上下左右偏移，所见即所得。

* **✂️ AI 智能切割 (多人物处理)：** 拖入包含多个形象的图片，AI 自动识别并框选出每个人物。支持鼠标手动增删、调整选框，一键切分成多张标准图片。

* **🤖 AI 智能重命名：** 一键看图识物，自动将原始乱码文件名转换为精准的描述性名称（如 `黑猫_240x240.png`）。

* **🔒 纯本地安全处理：** 图像的核心缩放、裁剪与格式转换 100% 在本地浏览器完成。（仅在使用 AI 功能时会发送微缩图片特征）。

## 🚀 快速上手 (四步搞定)

1. **导入图片：**
   * **多人物图片：** 拖入顶部的**紫色切割区域**，进行识别与拆分。
   * **普通图片：** 直接拖入下方的**普通处理区域**。

2. **位置调整（可选）：** 拖动中部的三个滑块（留白比例、水平偏移、垂直偏移），列表中的图片会瞬间实时跟随变化，直到你满意为止。

3. **AI 重命名（可选）：** 点击紫色的 “✨ AI 智能重命名” 按钮，让 AI 帮你批量改名。

4. **一键导出：** 勾选满意的图片，点击“下载选中的图片”直接保存到电脑。

## 💡 操作小贴士

* **如何手动切割？** 在切割界面的图片上，按住鼠标拖动即可画出新选框；拖拽边角可改变大小；选中框后按 `Delete` 键可删除。

* **觉得切出来的人物太满？** 只要把中间的 **“统一四周留白比例”** 滑块向右拉一点，人物就会立刻缩小，显得更清爽。

* **建议处理量：** 为保证浏览器流畅度，建议单次批量处理不超过 100 张。
